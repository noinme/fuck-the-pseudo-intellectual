## 二、警方以后可能作出的处理

“回执”主要证明收到报案；最终处理通常需要看相应决定或通知。以下是可能分支，均不表示本案已发生。

| 可能结果 | 应重点阅读的内容 | 对后续维权的用途 |
|---|---|---|
| 行政处罚 | 认定的具体行为、时间、证据、法律依据、处罚及救济告知 | 作为民事诉讼或校方投诉的重要书证；行政处罚不会自动解决赔偿 |
| 有违法行为但依法不予处罚 | 哪些事实已被认定、为何依法不罚 | 已认定事实仍可能支持民事责任；不罚不等于行为不存在 |
| 违法事实不能成立而不予处罚 | 哪些关键事实不能确认、证据或法律适用方面的理由 | 评估补证和救济；民事诉讼仍须面对实际证据缺口 |
| 涉嫌犯罪，依法转入刑事处理 | 转入程序的实际通知、承办情况及新要求 | 后续按实际刑事程序更新；转入不等于定罪 |
| 依法终止调查 | 具体理由、事实及依据，例如没有违法事实、超过追究时效等 | 判断是否需要救济，不能将各种终止理由混为一谈 |

前四类处理依据《治安管理处罚法》第113条；终止调查情形见《公安机关办理行政案件程序规定》第259条。[法律全文](https://www.npc.gov.cn/npc/c2/c30834/202506/t20250627_446254.html)、[程序规定](https://jtgl.beijing.gov.cn/jgj/jgxx/flfg/gabgz/744068792/index.html)。

若最终适用2026年施行的《治安管理处罚法》第52条第一款，通常猥亵行为的拘留幅度为5至10日，该款规定的严重情形为10至15日；具体适用还涉及法定裁量、减免及执行条件，不能仅凭目前案名预测结果。有被侵害人的，处罚决定书应向其送达，见第116条。[法律依据](https://www.npc.gov.cn/npc/c2/c30834/202506/t20250627_446254.html)

调解有法定范围并须自愿，不因双方认识而自动适用。将来若出现调解或和解提议，应核对其依据、事实记载、履行内容及对民事请求的影响，不预先记为本案必经步骤。[《治安管理处罚法》第9条](https://www.npc.gov.cn/npc/c2/c30834/202506/t20250627_446254.html)

## 三、如何使用警方文书与调查材料

| 使用场景 | 具体做法 | 边界 |
|---|---|---|
| 查询警方进度、补充材料 | 按文书信息定位案件；提交时注明材料编号、版本及证明事项，保留接收记录 | 不把仓库全部材料视作已提交或已核验 |
| 律师咨询 | 提供完整决定、收到日期、现有证据目录和明确诉求 | 咨询草稿不证明咨询已发生；律师意见单独记录来源和日期 |
| 民事诉讼 | 以决定书支持其明确认定的事实，并提交原始证据及损害材料 | 不自动保证胜诉或赔偿金额 |
| 校方投诉及保护请求 | 经当事人决定，提供用途所必需的文书和材料，列明具体请求 | 处分仍需依据适用校规和调查程序；不自动对应某项处分 |
| 对警方处理寻求救济 | 分析事实遗漏、证据评价、法律适用及程序问题 | 审查对象是警方行政行为，与向对方索赔不同 |

《民法典》第1010条规定性骚扰民事责任以及学校等单位的相关预防、投诉受理和调查处置义务。[法律依据](https://www.court.gov.cn/zixun/xiangqing/233181.html)

依法制作的公文书证所记载事项原则上推定真实，但可被足以推翻的相反证据否定。处罚决定书的证明范围取决于其实际内容；报案登记或对某人陈述的记载，不等于其中每项指控均已查证。法院还会审查其他证据。[民事诉讼法司法解释第114条](https://sdcourt.gov.cn/hzzy/365314/365346/365327/8369071/index.html)

调查中的对方陈述、证人证言、电子数据提取记录等可能有独立价值。并非当事人可以直接取得全部案卷；对于国家机关保存、本人及代理人因客观原因不能自行取得的必要证据，可在民事诉讼举证期限届满前书面申请法院调查收集，由法院审查关联性与必要性。[同一司法解释第94—95条](https://sdcourt.gov.cn/hzzy/365314/365346/365327/8369071/index.html)

## 四、行政处罚后能否再起诉对方

可以。行政责任不替代民事责任，依据《民法典》第187条。向对方请求承担民事责任叫“提起民事诉讼”；不服法院一审裁判再请求上级法院审理，才是通常所说的“上诉”。民事起诉不以先有行政处罚为必要前提。[《民法典》](https://www.court.gov.cn/zixun/xiangqing/233181.html)

以下是供当事人选择及律师评估的诉求，不代表已经决定提出，也不保证法院支持：

| 可评估诉求 | 需要准备的事实和材料 |
|---|---|
| 赔礼道歉 | 侵害行为、影响范围以及希望采用的具体方式；法院会结合侵害情况判断 |
| 停止侵害 | 实际仍在持续或反复发生的侵害及相关记录 |
| 实际损失赔偿 | 真实存在的就医、支出或其他损失，金额凭据及与行为的因果关联 |
| 精神损害赔偿 | 侵害造成严重精神损害等法定条件的支持材料；不替当事人添加诊断或损害 |

相关依据包括《民法典》第179、1000、1010、1183条。[法律全文](https://www.court.gov.cn/zixun/xiangqing/233181.html)

处罚决定主要帮助证明其认定的侵害行为；赔偿项目、金额和关联仍需证据。若决定后来被撤销或变更，及时记录并重新评估其作用。实际起诉前，还需结合被告、诉求及案件情况核对管辖、诉讼时效、费用和可申请调取的证据。本稿不计算本案诉讼时效，也不以等待警方结果替代期限核对。

## 五、如果不认可警方的处理

认为警方决定侵犯当事人合法权益时，可以结合利害关系及具体决定评估行政复议或行政诉讼。民事索赔诉讼不能直接要求增加行政拘留天数。

- 行政复议一般为知道或应当知道行政行为之日起60日内申请，存在法定例外及特殊起算规则。[《行政复议法》第20条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_70518816df484be18f6b38fa295750bb.html)
- 直接提起行政诉讼一般为知道或应当知道行政行为之日起6个月内；经复议再起诉的期限不同。是否须先复议、具体期限及起算，按实际争议和届时规则核对。[《行政诉讼法》第44—46条](https://www.npc.gov.cn/zgrdw/npc/xinwen/2017-06/29/content_2024894.htm)

以上是一般规则，不是本案截止日期。收到决定时保留完整文书、信封或电子送达记录，尽快核对救济告知；不能照搬当前立案告知书中针对“不予立案”的模板说明。

## 六、收到新反馈后的更新方法

1. 在[案件进展记录](<案件进展记录.md>)追加节点，分别记录发生、收到及整理日期；保留原始文书，不覆盖旧文件。
2. 为新材料补相对路径与页码、段落或时间戳。电话消息标为通话记录或转述，不当作已收到书面决定。
3. 分开摘记“认定了什么”“未认定什么”“处理及理由”“要求和期限”，只摘必要内容。
4. 将已提交、已固定、尚待补交材料分别对应到[材料索引](<材料索引.md>)编号，不凭推断补全警方案卷范围。
5. 根据当事人的实际诉求更新本指南适用部分；律师意见记录日期、来源及适用前提。程序发生变化时重新核对法律依据。
6. 旧记录有错误时追加更正依据，并更新当前摘要。仅在决定起诉或制作对外材料后，另建相应用途草稿。
